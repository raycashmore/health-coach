# Learning companion design

The owner approved a restrained reading interface with strong typography, persistent navigation, search, expandable detail and compact evidence tables. This pinned direction governs this standalone surface; it does not change either application's visual design.

Use a serif reading hierarchy and a system sans for explanatory text and controls. Muted green surfaces and high-contrast green links support long reference sessions. Respect system light/dark preference. Keep body text within a readable measure, show focus clearly, and reduce the navigation to a wrapping row on small screens.

The first view explains the learning thread and offers four linked starting points. Experiments use a consistent question/method/result/lesson/limits structure. Concepts link back to experiments. Search spans both libraries and exposes an explicit empty state. Native disclosure controls reveal examples and limitations without obscuring the core explanation.

No decorative imagery or animation is needed. The bar comparison uses actual recorded required-passage counts, names the distinct runs, and keeps labels visible as text.
