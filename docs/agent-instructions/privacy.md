# Privacy and public-repository safety

- Treat every tracked file and every reachable Git commit as public.
- Keep real data only in local ignored files.
- Use generic labels and placeholder values in database schemas, documentation, tests, fixtures, screenshots, examples, and other tracked artefacts.
- Before a public push, inspect tracked content and commit author metadata for identifying information.

Sensitive material includes real names, email addresses, usernames, account IDs, personal health data, credentials, tokens, source reports, screenshots, and evaluation content.
